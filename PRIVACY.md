# Scapare Privacy Policy / 隐私政策

Last updated / 更新日期: 2026-10-03

This policy covers the Scapare macOS app, developed by Yiming GAO.

## Data processed on your Mac

Scapare does not require an account and does not send screenshots, imported images, recognized text, clipboard contents, or app usage statistics to the developer. It contains no advertising, analytics, or tracking service. Screenshot capture, annotation, scrolling-image stitching, OCR, barcode recognition, and image processing take place on your Mac.

Screen capture uses macOS screen recording permission. You can manage this permission in System Settings. Clipboard content and user-selected files are read when you use the corresponding capture, paste, import, or editing features. Scapare does not access your camera or photo library through a camera or photo-library integration.

Preferences and saved desktop pins are stored locally. Pins and editable pin backups can contain original images, editable annotations, and source text. Exported editable backups may retain information concealed by annotations; use a flattened image when sharing redacted content. You control the files you save or export and any sharing action you initiate through macOS. Scapare does not operate a cloud storage or synchronization service.

## Optional network image imports

Scapare connects to the network only when you choose to import an HTTPS image and confirm the destination shown in the app. The image host receives the requested URL and the network information needed to deliver the image, such as your IP address. These requests use an ephemeral session with cookies disabled. The developer does not receive these requests or the downloaded image. The image host's own privacy practices apply to that connection.

## Optional local automation

Command-line automation is disabled by default. When enabled, it uses a local Unix socket restricted to your macOS user account. It does not expose a network server. Commands process images and text on the same Mac.

## Support and policy updates

If you contact the developer through GitHub, the developer receives the information you choose to include in that message, and GitHub's privacy policy applies to use of that website. Do not include private screenshots or other personal information in public issues. Support information is used to respond to your request. Changes to this policy will be published on this page with an updated date.

Contact: [Scapare support](https://github.com/Alex-cloud0413/scapre/issues).

## 中文说明

Scapare 无需账号，不向开发者发送截图、导入图片、识别文字、剪贴板内容或使用统计，不包含广告、分析或追踪服务。截图、标注、长截图拼接、OCR、条码识别与图像处理均在 Mac 上完成。屏幕录制权限可在 macOS 系统设置中管理；剪贴板与所选文件用于用户主动发起的粘贴、导入和编辑操作。

偏好设置和保存的贴图存储在本机。可编辑贴图备份可能包含原图、标注和来源文字，标注遮挡的信息可能仍保留在原图中；分享脱敏内容时请导出已合成的图片。文件保存、导出和系统分享由用户操作控制，Scapare 不提供云存储或同步服务。

仅在用户选择 HTTPS 图片导入并确认目标后，App 才会请求该图片。目标图片网站会收到请求网址及传输所需的 IP 地址等网络信息；请求使用禁用 Cookie 的临时会话。开发者不会收到这些请求或图片，目标网站的隐私规则适用于该连接。

命令行自动化默认关闭，启用后仅通过当前 macOS 用户可访问的本机 Unix socket 通信，不开放网络服务器。通过 GitHub 联系开发者时，开发者仅收到用户主动提供的支持信息；公开问题中请勿包含私人截图或个人资料。政策更新会在本页面发布。
