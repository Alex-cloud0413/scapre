# Scapare 1.2.1（16）：双向与跨页固定侧栏去重

用户真机长图第二页为 App Store Connect，左侧导航固定，正文上下往返滚动后出现反复追加的侧栏文字。

## 根因与验收缺口

位移匹配已有固定列排除逻辑，正文能够正确对齐；输出仍将整行像素作为新增条带保存，所以静止侧栏被按正文位移反复追加。旧侧栏测试只检查正文列及长图高度，没有检查侧栏列。双向、跨页也没有改变这一输出缺口。

新增完整像素断言在修复前第一次 3 像素滚动就失败。验收现在覆盖整张图，包括侧栏和正文，不以正文匹配成功或输出变高作为通过条件。

## 修复

- 首次验证到真实滚动时，识别同屏位置保持不变、跨多个高度区域含文字/装饰的列区间。平坦留白和局部小图标不构成固定侧栏。
- 只处理静止文字与装饰的列包围范围，保留旁边的白色空隙，避免后续较长正文被误抹掉。
- 与已确认的正文位移交叉核对；整行高度滚动时仍能对齐的重复表格标签保持为正文，不误当成侧栏。
- 一页的侧栏保存原始视口像素一次，放在该页顶部的正文区域。新增长度只延续每列的主要背景色，不拉伸文字、不重复最后一行。
- 侧栏文字不参与局部页眉/页脚装饰判断；固定页眉、页脚和窗口圆角保持既有处理。
- 每页各自保存侧栏合成信息，封存后按该页位置绘制。预览和最终导出使用同一合成信息，后续页面不会覆盖此前页面。
- 采集与位移匹配不等待滚动停止；侧栏只在输出合成阶段处理，正文条带仍保留原像素。

## 验证

新增 1×/2×、左/右/双侧栏、向下、向上扩展和往返场景。每次接受画面后，都将完整输出与已知正确图像逐像素比较；跨页测试覆盖「无侧栏正文 → 左侧栏双向 → 右侧栏」并核对完整页面、空白间隔和正文顺序。

重复表格、固定顶/底栏、局部窗口圆角、留白、中文小数像素运动、流式采集、完成复制和功能引导继续使用原有回归检查。

可选附件重放使用用户图片中尚未重复的 App Store Connect 左侧栏像素，配合位置已知的正文，验证连续双向移动后的完整结果。该重放不是原始录屏还原或浏览器桌面操作；附件与重放图不写入 Git 仓库。

完整回归 **478 项通过**，其中新增 150 项覆盖固定侧栏完整输出、重复表格与小数像素起步、三页组合和附件侧栏重放。附件重放包含 15 个双向位置及最终图像保存核对，完整输出逐像素符合已知正文和单份侧栏。没有操作原始浏览器进行桌面实测。
