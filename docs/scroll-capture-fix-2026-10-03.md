# Scapare 1.1.1 (4)：滚动截图与工具栏提示修复

用户反馈：框选后点击工具栏的长截图按钮没有可见响应；工具栏悬停不显示功能说明。

## 修复

- 滚动截图使用的 `NSPanel` 原先采用默认的 `hidesOnDeactivate = true`，而进入滚动截图时需要激活原应用。现在控制面板和选区边框都明确保持可见，并支持全屏空间。选区边框不拦截鼠标，控制面板优先放在选区外。
- 进入后立即显示准备状态；随后提示向下滚动、等待画面稳定、已拼接、暂停或错误，并提供累计尺寸和实时预览。完成后进入已有图片编辑器；关闭和取消会释放采集任务。
- 小于 32 × 64 点的选区现在会显示扩大选区的提示，不再静默返回。
- 所有主工具栏按钮、菜单和粗细控件均提供功能提示。提示直接绘制在截图窗口内，放在工具栏滚动容器外，避免系统工具提示被高层级截图遮罩覆盖。提示不拦截点击，移出或关闭工具栏会消失。
- 稳定帧检查改为固定采样，避免在主线程执行完整重叠匹配。实时预览按条带缩小绘制，避免每次刷新都创建第二份完整长图；预览不会撑大控制面板。

参考飞书的框选、滚动、结束截图流程。本版仍由用户手动向下滚动、程序自动拼接，没有加入自动驱动原应用滚动或向上扩展图片。

## 验证

104 项回归检查通过，包括：真实工具栏按钮的 target/action 调用链、选区传递、小选区反馈、实际 hover 路由、所有按钮提示覆盖、提示边界与点击穿透、异步合成帧采集与完成按钮、错误状态和取消清理、预览像素顺序与尺寸上限、偏移显示器上的面板位置。

已检查合成数据下实际 AppKit 控件的渲染，修正了提示截断和预览撑大面板的问题。测试不截取用户桌面，不发送系统输入事件，不改写用户剪贴板。

电脑控制连接仍超时，因此不能把上述回归和控件渲染视为已完成真实网页滚动测试。需要用本机 1.1.1 (4) 复测：框选滚动内容、点滚动截图、在框内缓慢向下滚动并停顿、观察预览、完成并编辑；同时检查悬停提示。长图应避免固定页眉和动画区域。
