# Scapare 1.1.4（9）：长图底部窗口阴影重复修复

用户提交的长图在底部包含大量重复灰色条带和窗口圆角边缘。

## 原因和改动

固定页脚识别原先只统计同一行内的横向灰度变化。窗口底边与阴影通常横向一致、纵向渐变，因而没有被识别为固定边缘。正文位移匹配成功后，程序将视口底部的静止阴影随新增行重复追加。

行特征的边缘能量现在同时统计相邻行的纵向灰度变化。固定窗口阴影可进入既有页脚保留流程，只保留在输出末尾一次。正文位移验证、连续视频帧采集和原始输出像素不变；没有增加等待滚动停止的条件。

## 验证

- 新增「滚动正文 + 固定窗口阴影」用例，在修复前稳定失败，修复后每个输出阶段逐像素等于原始正文加一份阴影。
- 阴影边界精确识别，不包含相邻正文中的白色行。
- 连续小步滚动、较快位移、回滚后继续向下均不会重复追加阴影。
- 对首尾都包含大片白色留白的文档，边缘识别不会将留白误判为固定窗口装饰；输出逐像素保留原文档。
- 148 项完整回归检查通过，包括既有固定侧栏、局部动画、中文小数像素位移、复制、暂停和结束流程。
- Release 构建支持 Apple silicon 和 Intel；Developer ID 签名验证通过，保留 App Sandbox，无调试权限。

## 版本和实机边界

本机修复版为 1.1.4（9），Bundle ID 仍为 `com.gaoyiming.SnapTool`。没有自动操作用户的原网页滚动；原网页实机验收由用户进行。App Store Connect 已等待审核的 1.1.3（8）仍是此前提交的构建，本次修复尚未替换待审版本。

复测：确认「关于 Scapare」为 1.1.4（9），在同一页面使用原框选范围连续向下滚动，完成并复制后检查正文顺序、窗口底边和阴影是否只出现一次。
