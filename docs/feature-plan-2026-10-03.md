# Scapare 功能扩展约定

基线：f4f3e03。新增长截图，同时以 Snipaste 官方主页及 Pro 功能表为功能证据，比较 macOS 可用的截图、标注、贴图、恢复和输出流程。实现独立代码，保留 Scapare 名称、原 Bundle ID、图标和本地处理模式。

长截图采用「框选内容 → 在原 App 手动滚动 → 自动捕获并验证重叠 → 完成后编辑/保存」；不把简单的多图上下排列冒充自动拼接。不确定、反向滚动、过大跳跃或尺寸改变时应保留已完成部分并提示；限制内存和长度；取消可退出，完成可预览。

对标优先覆盖跨平台常用能力及有明确用途的 Pro 项目：精确/延时/重复/窗口截图，取色，白板，重编辑与脱敏标注，剪贴板/文件贴图，变换、分组和恢复，快捷导出与本地文字/条码识别。Windows 集成、商业授权策略和竞品外观不是 Scapare 功能缺陷。

主操作保持可发现，更多工具放入原生菜单/检查器；标注支持撤销；丢失文件、取消面板和无法拼接有恢复路径。构建/算法测试和运行界面验收分别记录，不能用前者替代后者。
