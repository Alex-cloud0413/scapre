# Scapare 1.2.0（15）双向与跨页长截图

参考用户的「长卷」仓库 `Alex-cloud0413/changjuan`，核对提交 `b395c1621e88aa1422c1760d84b75fdbe24d175a` 的 `Shared/OverlapEstimator.swift`、`LongShotApp/FrameStitcher.swift` 与 `ScreenCaptureCoordinator.swift`。

## 使用

- 框选内容后点击长截图按钮。在同一区域上下滚动，既可从顶部向下，也可从页面中间或底部向上开始。每页按内容位置排列；回到已截区域不重复追加。
- 换页：点击「切换页面」，切到目标网页、界面或 App，在原框选区域显示新内容后点击「继续追加」。完成时各页按追加顺序合成一张长图，页间保留空白间隔。
- 暂停后「继续」用于同页恢复；「切换页面 → 继续追加」明确创建独立页面，避免把跳转动画或一次失去重叠的快速滚动当成新页。
- 完成可直接复制或打开编辑器。静态页也可作为新页追加；退出或未获得新页画面时，不创建空页。

## 实现

- 每页保持带符号的内容位置与已捕获上下边界；只保存新的上方和下方行，保留原像素。
- 固定页眉、页脚与边缘圆角分别置于页面两端；向上扩展时更新顶端，向下扩展时更新底端。
- 跨页复用会话与预览，明确封存旧采集源、清空其队列，再启用新源；过渡画面不参与拼接。
- 仍使用连续 ScreenCaptureKit 帧、稠密像素校验与小数像素位移精修。无法可靠衔接的同页帧保留此前结果，不猜测缺失内容。
- 每个会话仍限制总高度 30,000 像素、总面积 60,000,000 像素；分页不会绕过上限。

## 验证

验证以已知源页面的像素与行顺序为准，覆盖中英文段落、代码、表格、卡片、留白、1×/2×分辨率，倒序、两端扩展、往返、固定栏与圆角、连续小数像素运动、显式跨页与静态页。原生控制器验证换页时停旧源、继续时启新源、跨页复制及新源准备期间立即完成的状态。
