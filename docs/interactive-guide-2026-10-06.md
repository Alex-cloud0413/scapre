# Scapare 1.1.9（14）实操功能引导

沿用 Bundle ID `com.gaoyiming.SnapTool`。菜单栏与设置的入口均为「功能引导」，替换 1.1.8 的纯文字内容；首次启动仍自动显示。

## 操作

- 七个主题：快速开始、截图与取色、滚动长截图、标注与保存、桌面贴图、文字与条码识别、更多功能。
- 每次只显示当前任务；成功框选、标注、撤销、复制、移动等操作后才启用下一步。可切换主题、重新练习或随时关闭。
- 使用内置 Retina 练习卡片、二维码与原生可滚动练习页。编辑器、工具条、贴图窗口、Vision 识别与长图拼接器均使用生产组件。
- 复制到实际剪贴板；保存仅在主动点击保存后弹出系统面板。引导练习无需捕获桌面。
- 练习贴图不加入用户贴图库；退出、切换主题或重新练习会释放贴图、识别任务与长图面板。练习快捷键和主题不改动已保存的日常设置。

## 验证

- 生产源码回归脚本：294 项检查通过，包含步骤顺序、不可跳过、真实编辑与撤销重做、图像和文字复制、临时贴图、实际 OCR/QR、临时快捷键和主题、练习页长图拼接与退出清理。
