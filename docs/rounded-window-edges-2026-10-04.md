# Scapare 1.1.6（11）：窗口和侧栏圆角重复

## 附件与复现

用户提供的 3840×4680 长图在左右窗口边缘、侧栏与页面交界处出现多次向下重复的圆角和阴影。主要异常来自窗口装饰被反复追加；不能据此断言整张正文都没有其他问题。

固定边缘原先复用了正文位移描述子，采样范围避开最外侧列，并要求整行近似静止。因此，“只有两侧圆角固定、中间正文仍滚动”的底部区域无法被识别为固定边缘。上一轮测试覆盖整条固定阴影和正文像素，没有覆盖整张带局部圆角的输出，验收范围不充分。

- 新增确定性窗口/内侧栏圆角测试：旧版在第一次 3 像素滚动后，即与完整正确输出不一致。
- 附件首个约 2100 行视口用于本地重放：保留真实边缘像素，正文替换为位置已知的测试内容。旧版识别底部边缘为 0 行，第一次 3 像素滚动就重现输出差异；修复后识别需保留的边缘范围为 49 行。
- 附件本身未提交到代码仓。`Tools/ReplayRoundedWindowEdges.swift` 是针对该尺寸的本地诊断工具，不是浏览器实机测试，也不等于恢复了当时的原始视频帧。

## 修复

1. 输出边缘识别检查所有像素列的静止纵向变化，包括最外侧和内部侧栏圆角；平坦留白与单个微小波动不构成固定边缘证据。
2. 窗口装饰的输出保留范围与正文位移校验范围分开。部分列固定时，中间正文仍可参与位移校验，避免边缘处理改变正文的匹配判断。
3. 整个底部保留区只放在输出末尾，其间的正文由连续内容和最终末尾画面共同覆盖。新增行不能跨过可用正文范围。
4. 向回滚动不会把长图末尾替换成较早页面的底部，避免圆角之间的正文被覆盖或重复。
